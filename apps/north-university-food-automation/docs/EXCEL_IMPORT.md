# EXCEL IMPORT

فرمت واقعی فایل معاونت هنوز دریافت نشده؛ بنابراین تطبیق ستون‌ها دستی/خودکار است.
قالب پیشنهادی (ردیف اول عنوان): شماره دانشجویی | کد ملی | نام و نام خانوادگی (یا نام + نام خانوادگی) | دانشکده | رشته | مقطع | سال ورود

جریان: Upload → Parse (مرورگر، فقط مقادیر؛ فرمول/HTML نادیده) → Validate+Stage (سرور) → Preview → Confirm → Commit (upsert دسته‌های ۱۰۰تایی) → Report.

کنترل‌ها: xlsx/xls/csv، ≤ ۵MB، ≤ ۳۰۰۰ ردیف؛ اعتبارسنجی چک‌سام کد ملی؛ تکراری‌ها در فایل؛ تعارض کد ملی با دانشجوی دیگر؛ تشخیص جدید/تغییر/بدون تغییر؛ اثرانگشت فایل برای هشدار واردسازی تکراری؛ پاک‌سازی پیشوندهای فرمولی؛ گزارش خطا با شماره ردیف (CSV).

سیاست خطا (انتخابی): «رد کامل در صورت هر خطا» (پیش‌فرض) یا «ثبت ردیف‌های معتبر».
ثبت: تراکنش واقعی چندعبارتی در دسترس نیست؛ upsert بر اساس شماره دانشجویی idempotent است. در صورت توقف، دسته «Failed» می‌شود و تأیید مجدد بدون تکرار ادامه می‌دهد.
کد ملی خام هرگز ذخیره نمی‌شود (stagedData فقط هش دارد). وضعیت دانشجویان موجود توسط واردسازی تغییر نمی‌کند.
