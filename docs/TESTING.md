# TESTING

**وضعیت صادقانه: هیچ تست خودکاری نوشته یا اجرا نشده است.** تنها بررسی انجام‌شده: TypeScript compile توسط محیط Zite.

برنامه‌ی تست (برای اجرا در بک‌اند مستقل با PostgreSQL واقعی و Vitest/Playwright):
- ورود: معتبر، کد ملی اشتباه، غیرفعال، ناقص، ۵ تلاش ناموفق، بدون نشست، نشست منقضی
- Import: معتبر، نامعتبر، ستون ناقص، تکراری، کد ملی نامعتبر، فایل بزرگ، لغو، گزارش خطا، توقف میانه
- رزرو: موفق، ظرفیت پر، موجودی ناکافی، تکراری، لغو مجاز/دیرهنگام، رقابت برای آخرین ظرفیت، retry با همان کلید
- مالی: موجودی منفی، ثبت تکراری، تطبیق، مجوز شارژ، دلیل الزامی
- QR: معتبر، نامعتبر، لغوشده، تحویل تکراری، دو اسکن هم‌زمان، کاربر فاقد مجوز
- RBAC: فراخوانی هر endpoint با هر نقش
- سناریوی هم‌زمانی: RESERVATIONS.md
