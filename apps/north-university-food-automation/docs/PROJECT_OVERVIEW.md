# PROJECT OVERVIEW

## هدف
جایگزینی سامانه‌ی فعلی تغذیه با سامانه‌ای امن، فارسی (RTL) و قابل ممیزی.

## نقش‌ها
دانشجو، معاونت دانشجویی (StudentAffairs)، مدیر ارشد (SuperAdmin)، پیمانکار (Contractor)، اپراتور سلف (Operator)، مسئول مالی (Finance). ماتریس کامل: RBAC.md

## تصمیم‌های قطعی پیاده‌شده
- ورود دانشجو فقط با شماره دانشجویی + کد ملی؛ بدون رمز عبور.
- کد ملی فقط به‌صورت HMAC-SHA256 (کلید `ZITE_NATIONAL_ID_PEPPER`) و ۴ رقم آخر ذخیره می‌شود.
- کیف پول مبتنی بر دفترکل فقط‌افزودنی؛ موجودی همیشه از جمع تراکنش‌ها محاسبه می‌شود.
- درگاه پرداخت غیرفعال؛ هیچ فراخوانی درگاهی در کد وجود ندارد.
- واحد پول در کل سامانه: **ریال، عدد صحیح**.
- منطقه‌ی زمانی عملیاتی: Asia/Tehran؛ نمایش تاریخ شمسی.
